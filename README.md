# 📦 Inventory & Order Management System

A full-stack Inventory and Order Management application built using **Node.js, TypeScript, MySQL**, and **Handlebars (HBS)**.

This project follows **OOP principles**, **SOLID design principles**, and uses a **Repository Pattern + Service Layer architecture** for clean and scalable code.

---

## 🚀 Features

### 📦 Product Management
- Create product
- Update product
- Delete product
- View product list
- Search products
- Pagination support

### 🛒 Order Management
- Create order
- Automatic stock deduction
- Prevent ordering beyond available stock
- View orders with product names (JOIN)
- Pagination support

## 🏗️ Design Patterns Used

- **Repository Pattern** → Abstracts database logic
- **Service Layer Pattern** → Handles business logic
- **Dependency Injection** → Loose coupling
- **OOP Principles**
  - Encapsulation
  - Abstraction
- **SOLID Principles**
  - Single Responsibility Principle (SRP)
  - Dependency Inversion Principle (DIP)

## ⚙️ Tech Stack

- **Backend**: Node.js, Express
- **Language**: TypeScript (ESM)
- **Database**: MySQL (mysql2)
- **Templating Engine**: Handlebars (HBS)
- **Tooling**: ESLint, ts-node
